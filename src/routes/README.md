# Routes

File-based routes (TanStack Router). `__root.tsx` is the app shell around every page.

| File | URL | Page |
| --- | --- | --- |
| `index.tsx` | `/` | Home |
| `auth.tsx` | `/auth` | Sign in / register |
| `dashboard.tsx` | `/dashboard` | Dashboard |
| `students.index.tsx` | `/students` | Student directory and skill search |
| `students.$id.tsx` | `/students/:id` | Student profile and direct request |
| `collaborations.new.tsx` | `/collaborations/new` | New collaboration requirement |
| `requirements.index.tsx` | `/requirements` | Requirements Board |
| `requests.tsx` | `/requests` | Request inbox |
| `architecture.tsx` | `/architecture` | DSA architecture (public) |

`src/routeTree.gen.ts` is generated by the router plugin; do not edit it by hand.
